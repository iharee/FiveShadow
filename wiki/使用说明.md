# 使用说明

## 启动

```sh
uv sync --locked
uv run stubble gui
```

macOS也可双击根目录 `启动.command`。当前机器已安装uv，Python 3.12与依赖由uv管理。此版本是可运行的Python桌面工具，尚未打包成独立.app安装包。

## 自动模式

1. 打开照片，程序在后台自动找脸和定位嘴角、下巴。
2. 有多张脸时，用下拉框选择要处理的人脸；默认面积最大的一张。每次生成处理一张脸。
3. 查看左图的脸框和三个彩色点。必要时直接拖动点位微调。
4. 点击“生成结果”，在右图查看结果。
5. 调整强度，或勾选“右侧暂看原图”比较同一位置；满意后另存PNG。

检测与修复都在本机子进程中完成。初次准备缺失的定位参数时会下载模型，不上传照片。修复不依赖网络。

## 手动模式

可先看[效果对照与点位示意](定位案例.md)。

1. 点击“手动选区”。
2. 在左图拖一个框圈住整张脸，包括眉眼、鼻子、嘴唇到下巴。
3. 按提示依次点画面左嘴角、画面右嘴角、画面中下颌轮廓的最低处。侧脸或歪头时，这个点可能与前突的解剖学下巴尖不同。
4. 点“生成结果”。

滚轮缩放，拖动空白处平移；标完三个点后可拖动彩色点调整。自动检测失败时也可切换到这里。若只想圈出人脸而不手动标点，可框选后点“在框内自动定位”。

“重新标记三个点”保留脸框、清除点位。重新选区、点位或修复版本会使旧预览失效，需重新生成；强度滑块则直接调整已有结果，不重跑网络。

## 命令行

```sh
# 默认自动定位+默认C模型
uv run stubble process --input photo.jpg --output runs/photo-C

# 选择第二张脸（索引按面积从大到小，从0开始）
uv run stubble process --input group.jpg --face-index 1 --output runs/person-2

# 限定脸部区域，区域内自动定位嘴角与下巴
uv run stubble process --input photo.jpg --box 2200 500 2850 1150 --output runs/crop

# 完全手动坐标，不调用自动定位
uv run stubble process --input photo.jpg --box 2200 500 2850 1150 \
  --points 2420 923 2528 936 2478 1010 --output runs/manual

# 复用GUI保存的定位
uv run stubble process --input photo.jpg --profile photo.stubble.json --output runs/reuse

# 只定位并导出JSON配置
uv run stubble detect --input photo.jpg --output selection.json

# B/C对照，使用同一份定位
uv run stubble compare --input photo.jpg --output runs/comparison
```

坐标是语法示例，应替换为自己的照片坐标；均以EXIF转正后的原始分辨率为准。`--box`顺序为左、上、右、下；三个点按画面方向区分左右。输出目录必须不存在。省略process的output时自动创建唯一 `runs/` 子目录。

可用 `--model B` 切换，`--strength 0.7` 调整强度，`--threads 6` 控制CPU线程，`--debug`保存ROI、mask、分割及中间数组。正常输出只有 `result.png`、`profile.json`、`manifest.json`。GUI的保存定位可与CLI互用。

## 文件与后台任务

原照片保持不变，GUI结果通过“另存”导出。后台任务可取消，也可关闭窗口结束任务。GUI工作缓存位于系统用户缓存目录下 `iharee/StubbleRemoval/jobs`（具体根位置由Qt决定）；其中保留本次后台处理结果和参数，可在退出软件后按需清理。

GUI强度对完整结果与原图做0..100%混合；CLI强度在回投差值时应用，因8位舍入/裁剪，两者可有少量像素舍入差异。界面中的0..100%不是原软件强度标尺。

目前支持8位JPG/PNG等RGB图像，不支持RAW/16位完整流程。ICC尽量保留，但没有实现完整色彩空间转换；源EXIF不整体复制到输出。

## 效果边界

新增自动定位使用YuNet与MediaPipe，提供三点仿射所需输入；不是恢复原生142点拟合。侧脸、发丝遮挡、小人脸和异常姿态可能定位偏差，请在预览上修正。已有较好人工评价来自原研究手工几何，不能将其直接当作自动模式在任意照片上的质量保证。

自动下巴选点已从固定MediaPipe152改为投影下颌轮廓最低处，并用相邻轮廓点插值。此前02170的侧脸会因两种定义相差约53像素而使C修正偏弱，单变量对照确认主要差异来自点位。旧运行保存的profile不会自动改写，需重新“自动定位”后再生成；手工配置与模型权重保持原样。
